MTG CARD LIBRARY - WINDOWS PACKAGE

1. Extract the ZIP to a normal folder.
2. Double-click START-MTG-CARD-LIBRARY.bat.
3. Your default browser opens the app at http://127.0.0.1:8765/.
4. Keep the command window open while using the app.
5. Close the command window when you are finished.

No Node.js, Python, npm, or separate web server installation is required.
The launcher uses Windows PowerShell and serves the app only on your own computer (127.0.0.1).

Collection/deck/buy-list data is stored by your browser locally. Use Import / Export in the app to make backups.
