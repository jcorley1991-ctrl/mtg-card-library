MTG CARD LIBRARY - ANDROID APK

Package: debug APK for direct testing
Application ID: com.jcorley.mtgcardlibrary
Target: Android 16 / API 36
Minimum: Android 7.0 / API 24

INSTALL
1. Download MTG-Card-Library-Android.apk to the Android device.
2. Open the APK.
3. Android may ask permission to install apps from the browser/files app used to open it. Allow that source if you trust this build.
4. Install and open MTG Card Library.

DATA
Collection, deck, and buy-list state is stored locally in the Android WebView profile. Use the app's Import / Export tools for backups.

BUILD STATUS
This is a direct-install debug build intended for testing the current Phase 1 v2 application. It is not a Google Play signed release build. Packaging does not change the authoritative requirements in docs/MASTER_SPEC.md.
