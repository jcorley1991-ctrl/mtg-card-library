# TCG Scanner V1

Android-native Magic: The Gathering scanner milestone.

Current milestone: live camera -> OCR -> exact-print lookup by set/collector when available -> artwork fallback across printings -> result display with card image, set, collector number, language, rarity, Oracle text, confidence, and price fallback.

Mana Pool remains the preferred pricing source for the project. V1 uses Scryfall pricing only as a clearly labeled fallback until authenticated Mana Pool API access is available.
